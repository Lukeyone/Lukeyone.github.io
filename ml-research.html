PyTorch computer vision

Custom convolutional neural networks were developed for nine-class agricultural-pest recognition and ten-class recyclable-waste classification.

82.81%pest test accuracy in the strongest defensible comparison
≈0.83pest weighted F1
70.30%waste in-domain test accuracy
  • Custom nn.Module architectures, convolution, pooling, batch normalisation, dropout and global average pooling
  • Adam and SGD comparisons, learning-rate and batch-size experiments
  • Weighted sampling for class imbalance
  • TensorBoard, confusion matrices and per-class precision/recall/F1
  • PyTorch Profiler analysis of image input pipelines
  • Independent real-world image testing that fell to approximately 50% accuracy, exposing domain shift
  • ResNet-18 on CIFAR-10 remapped to five coarse classes, reaching approximately 77% test accuracy in the recorded run
Failure analysis: an “improved” CNN was accidentally paired with an optimiser bound to the earlier model’s parameters. The near-chance result is not used as model evidence; it is documented as an implementation and experiment-validation lesson.

Geological language-model adaptation benchmark

A corrected, leakage-controlled experiment compared pretrained GPT-2, full-parameter fine-tuning and PEFT/LoRA on document-separated Australian geological corpora, with a related-geology test and an out-of-domain parliamentary control.

ModelGeological validation PPLRelated geology PPLOut-of-domain PPL
Pretrained GPT-224.64511.65717.903
Full fine-tuning25.27911.44818.930
LoRA24.85611.65818.254

Neither adaptation method improved held-out geological validation perplexity. Full fine-tuning produced only a 1.80% related-geology gain while worsening out-of-domain perplexity by 5.74%; LoRA was nearly neutral on geological performance and worsened out-of-domain perplexity by 1.96%.

98.7%fewer trainable parameters with LoRA
63.6%lower LoRA training runtime
62.5%lower LoRA peak GPU memory
  • Official Geoscience Australia sources with document-level train, validation and related-test separation
  • Token-weighted sliding-window perplexity and explicit out-of-domain retention measurement
  • Fresh pretrained, fully fine-tuned and LoRA model instances to avoid baseline contamination
  • Training curves, runtime, parameter and GPU-memory comparison
  • Fixed-prompt generation diagnostics and blinded human-review material
  • Reproducibility bundle containing source hashes, package versions, configuration, metrics and model metadata
Result: parameter efficiency did not translate into geological capability. Both adapted models began overfitting early, and generated continuations remained scientifically unreliable. The benchmark therefore rejects open-ended GPT-2 continuation as the target task and motivates grounded geological evidence extraction, structured outputs, page-level citations and explicit abstention.
Scope: this was a quick diagnostic run using 75 training chunks and nine validation chunks from a small, publisher-concentrated corpus. It supports conclusions about this pipeline and model setup, not broad geological-language generalisation.

Microclimate sensor clustering

Timestamped environmental observations were imputed, standardised and reduced with PCA before comparing K-Means, DBSCAN and agglomerative clustering.

MethodRecorded silhouette scoreInterpretation
K-Means≈0.226Weak but best of the tested partitions
Agglomerative≈0.165Limited separation
DBSCAN≈−0.516Poor density-based structure under tested settings

The project’s value is the conclusion that the selected sensor representation did not contain strongly separated natural clusters. The result was not reframed as a successful segmentation.

  • Missing-value treatment and standardisation
  • PCA retaining 95% explained variance
  • Dendrogram and visual cluster inspection
  • Method comparison with a consistent validation measure

Australian food classification

Decision trees and random forests were trained to classify Australian food categories from nutritional composition while reconciling multiple source tables and hierarchical labels.

87–89%recorded random-forest test accuracy
79–83%recorded decision-tree test accuracy
≈92%validation accuracy in selected configurations
  • Data-source compatibility analysis
  • Missing-value and constant-feature handling
  • Hierarchical food-class labels
  • Train/validation/test comparison and overfitting review
  • Decision-tree interpretability versus random-forest performance
Scientific judgement: per-100-gram and per-100-millilitre nutrient tables were not treated as interchangeable. The incompatible source was excluded from the primary model rather than merged for a larger but misleading dataset.

Common approach

  • Define the evaluation boundary before choosing the model.
  • Keep test data separate from training transformations.
  • Compare baselines and alternatives, including failed alternatives.
  • Inspect per-class and out-of-domain behaviour rather than aggregate accuracy alone.
  • Record implementation defects and methodological limitations.
  • Prefer an honest inconclusive result to a misleading success claim.
